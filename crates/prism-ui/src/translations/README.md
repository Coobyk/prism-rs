# Launcher translation catalogs

The German, French and Japanese catalogs adapt matching strings from
[Prism Launcher Translations](https://github.com/PrismLauncher/Translations/tree/290a55a24737a10287075b51696b980b67e8fb4a)
by the Prism Launcher translation contributors, licensed under [Apache 2.0](LICENSE-APACHE).
These files are modified: Qt mnemonics are removed, strings are adapted to this
launcher, and translations for prism-rs-specific UI are included.

Each JSON key is the English source text. Keep numbered placeholders such as
`{0}` in the translated value; they can be reordered. Missing keys use the
English source.
